안드로이드 하단 내비게이션과 길게 누르기 동작 다듬기

2026.11.251분 분량

  • Android
  • Kotlin
  • UX
  • Accessibility

일정과 활동을 관리하는 앱에서 목록 아래쪽 메뉴가 시스템 제스처 영역에 겹치고, 항목을 편집하는 방법도 바로 보이지 않는 문제가 있었습니다. 일정 입력 화면에서는 가장자리에서 조금만 움직여도 이전 화면으로 닫히는 일이 있었습니다. 각 동작의 원인을 나눠 수정했습니다.

시스템 내비게이션과 하단 메뉴

하단 메뉴 높이를 고정값으로만 두면 기기의 시스템 내비게이션 방식이나 화면 인셋에 따라 메뉴 일부가 가려질 수 있습니다. 시스템 인셋을 반영해 하단 영역 높이를 조정하고, 메뉴 항목의 콘텐츠가 실제로 쓸 수 있는 공간 안에 배치되도록 바꿨습니다.

목록에서 편집과 삭제

일정과 활동 항목을 길게 누르면 수정 또는 삭제 메뉴가 열립니다. 삭제를 고르면 확인 대화상자를 한 번 더 거치게 해 실수로 지우는 일을 줄였습니다. 일정은 기존 편집 화면을 열고, 활동은 상세 정보 수정 화면으로 이어집니다.

버튼과 뒤로가기 제스처

버튼 색을 테마 기본값에 맡기지 않고 배경과 대비가 분명한 색을 직접 지정했습니다. 입력 화면의 뒤로가기 제스처는 이동 진행률이 충분히 커졌을 때만 화면을 닫도록 조정했습니다. 툴바 뒤로가기와 기기의 뒤로가기 동작은 계속 사용할 수 있습니다.

확인한 범위

Android 실기기에 최신 Debug APK를 설치하고, 에뮬레이터에서 하단 메뉴와 버튼 표시 및 입력 화면 제스처를 확인했습니다. JVM과 Android 계측 테스트, Debug·Release 빌드와 lint도 실행했습니다. 모델 파일을 실제로 가져와 오프라인 추론하는 동작은 이 UI 작업의 검증 범위에 포함되지 않습니다.

기기별 화면 크기와 시스템 내비게이션 설정은 다를 수 있으므로, 새 기기 레이아웃이 추가되면 하단 영역과 제스처를 다시 확인해야 합니다.
