커서 기반 페이지네이션 쿼리 작성하기

2025.09.261분 분량

  • SQL
  • MySQL
  • Database
  • UMC

UMC 9기 Node.js 파트 2주차 미션으로, 가게 미션 앱의 화면별 쿼리를 작성했습니다. 목록 조회는 OFFSET 대신 마지막으로 본 행의 값을 커서로 넘기는 방식으로 페이징했습니다. 개념 정리는 DB 정규화, 인덱스, ORM과 Raw SQL에 있습니다.

내가 진행 중이거나 완료한 미션 목록

user_mission 테이블의 created_at 과 id 를 커서로 사용합니다. created_at 이 같은 행이 있을 수 있어서 id 를 함께 비교합니다.

첫 페이지

SELECT
    s.name AS store_name,
    m.reword,
    m.spac AS mission_condition,
    um.status AS is_completed,
    um.created_at,
    um.id
FROM user_mission AS um
JOIN mission AS m ON um.mission_id = m.id
JOIN store AS s ON m.store_id = s.id
WHERE um.user_no = "유저ID"
  AND um.status = "STATUS"
ORDER BY um.created_at DESC, um.id DESC
LIMIT 10;

다음 페이지

SELECT
    s.name AS store_name,
    m.reword,
    m.spac AS mission_condition,
    um.status AS is_completed,
    um.created_at,
    um.id
FROM user_mission AS um
JOIN mission AS m ON um.mission_id = m.id
JOIN store AS s ON m.store_id = s.id
WHERE um.user_no = "유저ID"
  AND um.status = "STATUS"
  AND (um.created_at, um.id) < ("마지막 created_at 값", "마지막 ID 값")
ORDER BY um.created_at DESC, um.id DESC
LIMIT 10;

홈 화면: 현재 지역에서 도전 가능한 미션

mission 테이블의 deadline, created_at, id 를 커서로 사용합니다.

현재 지역 미션 달성 현황

SELECT COUNT(um.id) % 10 AS mission_progress_count
FROM user_mission AS um
JOIN mission AS m ON um.mission_id = m.id
JOIN store AS s ON m.store_id = s.id
WHERE um.user_no = "유저ID"
  AND s.region_id = "지역ID"
  AND um.status = TRUE;

도전 가능한 미션 목록, 첫 페이지

이미 도전한 미션은 NOT EXISTS 로 제외합니다.

SELECT
    s.name AS store_name,
    s.industry,
    m.spac AS mission_condition,
    m.reword,
    m.deadline,
    m.created_at,
    m.id
FROM mission AS m
JOIN store AS s ON m.store_id = s.id
WHERE s.region_id = "지역ID"
  AND m.deadline > NOW()
  AND NOT EXISTS (
      SELECT 1
      FROM user_mission um
      WHERE um.mission_id = m.id
        AND um.user_no = "유저ID"
  )
ORDER BY m.deadline ASC, m.created_at DESC, m.id DESC
LIMIT 10;

도전 가능한 미션 목록, 다음 페이지

정렬 방향이 섞여 있어서(deadline 은 오름차순, 나머지는 내림차순) 튜플 비교를 쓸 수 없습니다. 그래서 정렬 기준마다 조건을 풀어 씁니다.

SELECT
    s.name AS store_name,
    s.industry,
    m.spac AS mission_condition,
    m.reword,
    m.deadline,
    m.created_at,
    m.id
FROM mission AS m
JOIN store AS s ON m.store_id = s.id
WHERE s.region_id = "지역ID"
  AND m.deadline > NOW()
  AND NOT EXISTS (
      SELECT 1
      FROM user_mission um
      WHERE um.mission_id = m.id
        AND um.user_no = "유저ID"
  )
  AND (
      (m.deadline > "마지막 deadline 값")
      OR (m.deadline = "마지막 deadline 값" AND m.created_at < "마지막 created_at 값")
      OR (m.deadline = "마지막 deadline 값" AND m.created_at = "마지막 created_at 값" AND m.id < "마지막 ID 값")
  )
ORDER BY m.deadline ASC, m.created_at DESC, m.id DESC
LIMIT 10;
