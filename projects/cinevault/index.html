화면

개요

TMDB 데이터를 이용해 상영작과 예정작, 장르별 영화를 탐색하고, 관심 있는 작품과 감상 기록을 브라우저에 보관하는 React 웹앱입니다. 저장한 별점과 장르를 바탕으로 편수, 평균 별점, 장르와 별점 분포를 계산해 개인 취향을 보여 줍니다.

주요 기능

  • 상영작·박스오피스·예정작·명작·장르별 영화 탐색
  • 제목 검색과 장르·연도·최소 평점·정렬 필터
  • 페이지 단위로 결과를 누적하는 더 불러오기
  • 출연진·감독·예고편·국내 관람등급·감상 경로를 묶은 상세 화면
  • 보관함·찜·별점 1~5·한 줄 평의 등록, 수정과 삭제
  • 보관 기록에서 편수, 평균 별점, 장르와 별점 분포 계산

구현에서 신경 쓴 점

검색창에 입력하는 값과 실제 API에 제출된 검색어를 분리해 타이핑할 때마다 요청하지 않도록 했습니다. 필터가 켜졌을 때는 TMDB discover 경로를 선택하고, 일반 탐색과 검색의 페이지 상태를 각각 관리했습니다.

보관함과 찜은 Redux Toolkit으로 상태를 관리하고 localStorage 접근을 유틸리티로 감쌌습니다. 같은 MovieCard와 필터 컴포넌트를 여러 페이지에서 재사용하고, 저장된 원본 기록에서 통계를 계산해 별도의 통계 데이터 복제를 줄였습니다.

현재 버전은 한 브라우저에서 개인 기록을 관리하는 구조입니다. 기록은 localStorage에 보관하고 API 키는 실행 환경에서 주입합니다. 다음 단계는 배포 서버를 두고 기기 사이에서 기록을 동기화하는 것입니다.

기술: React, JavaScript, Vite, Redux Toolkit, Axios, TMDB API
