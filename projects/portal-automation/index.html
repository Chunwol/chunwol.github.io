일정 포털 자동화

자동 입력보다 변경 범위·중복·결과 재조회를 먼저 검증하는 운영형 자동화

월간 일정과 학교 포털의 승인 배정·기존 기록을 연결해 근로 일지 입력을 안전하게 자동화하는 웹앱

개요

학교 포털의 근로 일지를 월간 일정과 연결해 관리하는 웹앱입니다. 로그인, 학교 계정 연결 확인, 반복 일정과 예외 편집, 승인된 근로 배정 선택, 기존 기록 조회, 자동 입력과 결과 확인을 한 흐름으로 묶었습니다.

사용자 흐름

  1. 웹앱 사용자와 학교 포털 연결 상태를 각각 확인합니다.
  2. 월·요일 반복 규칙과 날짜별 예외, 오전·오후 같은 여러 시간 구간을 편집합니다.
  3. 포털에서 현재 승인된 장학 유형과 근무지를 다시 조회합니다.
  4. 대상 월의 기존 기록을 먼저 읽고 중복될 날짜를 제외합니다.
  5. 승인한 월과 범위에만 입력하고, 등록 후 다시 조회해 실제 결과를 확인합니다.
  6. 수정·삭제도 요청 성공만 보지 않고 변경된 값이나 삭제 후 부재를 확인합니다.

안전한 자동화를 위한 결정

이미지나 일정표에 없는 날짜를 근무일로 추측하지 않고, 잘린 일정과 예외 시간은 사용자가 지정한 원본을 보존합니다. 어떤 날짜에 기존 일지가 하나라도 있으면 해당 날짜 전체를 건너뛰어 중복 입력을 막고, 빈 날짜에서는 필요한 여러 시간 구간을 함께 처리합니다.

실제 쓰기 시험과 조회 전용 확인을 월별로 분리했습니다. 특정 달의 임시 기록을 등록·수정·삭제한 뒤 원상 복구하고, 변경하지 않기로 한 달의 기록도 전후가 같은지 확인했습니다. 기능의 존재와 사용자별 예약 활성화 상태도 따로 관리합니다.

구현과 운영

Node.js와 Express로 사용자·일정·작업 API를 구성하고, Cheerio로 포털 응답을 해석합니다. 세션 갱신, 반복 규칙 이관, 기존 기록 조회 캐시와 작업 이력을 다루며 Docker와 GitHub Actions로 배포 경로를 관리합니다.

2026년 9월에는 운영 페이지와 health 응답, Docker 컨테이너의 healthy 상태를 직접 확인했습니다. 자동 시작 정책도 구성에 반영했지만, 실제 NAS 재부팅 시험까지 완료한 것으로 확대해 설명하지 않습니다. 계정 정보와 내부 접속 방식은 공개 포트폴리오에 포함하지 않습니다.

기술: JavaScript, Node.js, Express, Cheerio, Docker, GitHub Actions
