화면

개요

리폼러의 가격, 후기, 포트폴리오를 한곳에서 비교하고, 사진 한 장으로 여러 리폼러에게 맞춤 견적을 받을 수 있는 플랫폼입니다. 구매자는 리폼러가 만든 작업물을 사거나 직접 요청을 올릴 수 있고, 리폼러는 요청에 견적을 제안하거나 작업물을 판매합니다. UMC 9기 데모데이에서 최우수상을 받았습니다.

풀려던 문제

  • 리폼 정보가 SNS, 중고거래, 카페에 흩어져 있어 한 번에 비교하기 어려움
  • 가격과 서비스 기준이 불투명하고, 믿을 만한 후기가 부족함
  • 리폼러는 작업물을 한곳에서 관리하기 어렵고, 팔로워가 적으면 고객을 모으기 힘듦

핵심 기능

  • 리폼러의 작업물 판매와 구매
  • 사진과 설명으로 리폼 요청 등록
  • 요청에 맞는 리폼러의 견적 제안
  • 리폼러 프로필: 포트폴리오, 후기, 평점
  • 채팅으로 수거부터 작업, 발송까지 진행 상태 공유

제가 맡은 일

백엔드 팀원으로 참여해 23개의 Pull Request로 API를 구현했습니다. 홈과 탐색, 주문제작, 인증, 프로필, 카테고리, 결제와 재고에 걸친 기능을 맡았습니다.

백엔드 구성

  • Node.js, TypeScript, Express 5
  • TSOA와 Swagger UI로 API 문서 자동화
  • Jest, ts-jest로 테스트
  • 도메인 단위로 controller, service, model을 나눈 구조

문서

기술: Node.js, TypeScript, Express, MySQL, AWS
