개요

전공 동아리 ONE의 소개, 주요 활동, 프로젝트, 모집 공고와 캘린더를 방문자에게 보여 주고 관리자가 직접 운영할 수 있게 만든 웹 플랫폼입니다. 저는 백엔드 보일러플레이트와 ERD부터 관리자 인증과 콘텐츠 API까지 담당했습니다. 프론트엔드는 React와 Three.js로 구성했습니다.

담당 기능

  • 로그인과 JWT 기반 관리자 인증
  • 메인 로고와 프로젝트 생성·수정·삭제 API
  • 모집 공고 조회·수정 API
  • 캘린더 생성·조회·수정·삭제와 조회 그룹핑
  • 주요 활동 카드 수정·초기화
  • 입력값, 날짜, 파일 객체 키, 대량 삭제 요청 검증

백엔드 작업은 54개의 Pull Request로 남아 있습니다. 새 기능뿐 아니라 구조 정리와 수정, revert까지 포함해 관리자 인증부터 콘텐츠·모집·캘린더 API 전반을 맡았습니다.

백엔드 설계

도메인별 controller, request·response DTO, service, repository를 나누고 global 영역에서 공통 응답과 예외를 관리했습니다. 프론트가 오류를 구별할 수 있도록 응답 코드와 메시지 계약을 정리하고, Spring Security와 JWT 인증을 Swagger 문서에서도 시험할 수 있게 구성했습니다.

이미지는 애플리케이션이 직접 파일을 제공하는 대신 MinIO 객체와 presigned URL을 쓰도록 정리했습니다. 데이터베이스 변경은 Flyway migration으로 관리하고, 입력 경계는 Bean Validation과 도메인 검증을 함께 사용했습니다.

도메인 규칙을 코드에 반영한 사례

주요 활동은 자유롭게 행을 추가·삭제하는 목록이 아니라 1~4번의 고정 슬롯입니다. 그래서 삭제 요청도 실제 row 삭제가 아니라 슬롯 초기화로 처리해야 했습니다. 저장 방식보다 제품 규칙을 먼저 확인하고 API 의미와 구현을 맞춘 사례입니다.

캘린더 조회 그룹핑, 모집 기간 검증, 대량 삭제 검증, 파일 객체 키 처리처럼 화면에서는 작아 보이지만 계약이 어긋나기 쉬운 부분도 반복해서 보완했습니다.
