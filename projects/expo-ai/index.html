2026 동양미래EXPO(제44회 졸업작품전시회) 장려상

분리배출 기기 ECOMATE에 넣은 재활용품을 카메라와 무게로 판정해 수거 여부를 정하는 AI 서버

개요

ECOMATE는 폐기물의 종류와 상태를 분석해 올바른 분리배출 방법을 알려 주는 교육용 분리수거 기기입니다. 폐기물을 올려놓으면 카메라 이미지와 무게 센서 값으로 배출할 수 있는 상태인지 판단하고, 맞게 버린 경우에는 서보 모터가 수거 장치를 움직여 분류합니다. 그렇지 않으면 모니터에 이유와 피드백 영상을 보여 주고 다시 시도하도록 안내하며, 배출 기록은 앱에서 피드백 목록으로 확인합니다.

전공 동아리 ONE의 2026 EXPO 전시 작품으로 팀과 함께 만들어 2026년 10월 전시 운영까지 마쳤고, 저는 이 기기의 AI 서버와 모델 추론·검증·관제 인프라를 맡았습니다. 2026 동양미래EXPO(제44회 졸업작품전시회)에서 장려상을 받았습니다.

판정 흐름

  1. 라즈베리파이의 카메라와 무게 센서가 이미지와 무게를 AI 서버로 보냅니다.
  2. YOLO 모델이 물체의 위치와 9종 품목 후보를 찾습니다. 신뢰도 55% 미만이나 면적 10% 미만의 약한 BBox, 받침대 영역 밖의 사람·가방 오검출은 걸러내고 받침대 ROI로 fallback합니다.
  3. Vision LLM이 전체 화면과 확대한 물체 이미지를 함께 보고 품목, 라벨, 압착, 이물질을 판정합니다. 첫 판정에도 무게 센서 값을 보조 근거로 함께 전달하며, 찌그러진 캔이 플라스틱으로 오인되는 경우는 2차 이분 질문으로 다시 확인합니다.
  4. 규칙 엔진이 무게와 상태를 합쳐 수거, 거부, 일반 쓰레기, 미감지 중 하나로 확정하고 기기와 Spring 서버에 결과를 보냅니다. 안내 항목은 내용물 비우기 → 이물질 제거 → 라벨 제거 → 압착 우선순위로 다중 전송하며, 컵에 꽂힌 빨대(REMOVE_STRAW), 종이 컵홀더(REMOVE_CUP_HOLDER), 기타 이물질(FOREIGN_MATERIAL)을 구분했습니다.
flowchart TD
  P[Raspberry Pi 카메라 · 무게 센서] --> Y[YOLO 품목 후보 · 받침대 ROI 필터]
  Y --> L[Vision LLM 판정 · 클라우드 헤지 / NAS fallback]
  L --> R[규칙 엔진 · guidance 우선순위]
  R --> H[기기 응답]
  R --> S[Spring 서버]

캔, 종이, 비닐, 플라스틱(페트병)은 분류하고, 건전지, 유리, 형광등, 스티로폼은 분류할 수 없는 품목으로 인식해 모니터에 안내합니다. 압착 안내 역시 손으로 안전하게 눌리는 얇은 페트병·캔에만 적용하고 테이크아웃 컵이나 단단한 용기는 제외하도록 세분화했습니다.

맡은 일

  • FastAPI 분류 서버와 라즈베리파이 자동 배포 CI/CD 구성
  • 같은 입력으로 이전 판정을 다시 재현해 모델을 바꾸기 전후를 비교하는 검증 흐름과 데이터 누수 검사
  • 받침대 ROI 필터, 약한 BBox 차단, 찌그러진 캔·부착 이물질·안전 압착 규칙 고도화
  • NAS Ollama(MiniCPM-V 8B)와 GPU watchdog(CPU fallback 감지 시 자동 재시작), 다중 클라우드 Vision LLM 공급자 0.7초 헤지(Hedge) 호출 및 비상 fallback 구성
  • 요청 단계별 지연 시간, YOLO BBox, 공급자별 비용·상태를 실시간으로 확인하는 공개 웹 관제 페이지(/monitor) 구축

검증 결과

AIHub 재활용품 데이터에서 9종을 30장씩 고정해 뽑은 270장 회귀 평가에서는 259/270(95.93%, 위험 거부품 114/120)을 달성했고, 이후 실제 장비 카메라로 촬영한 유효 표본 69장에 대한 운영 평가에서는 응답 시간 단축과 함께 69/69 HTTP 성공, 품목 정확도 65/69(94.20%, 중앙값 1.78초)를 확인했습니다.

전시 일정을 마친 뒤 전용 GPU/Ollama 추론 자원은 안전하게 중지해 마무리했습니다.
