EXPO AI

분리배출 기기 ECOMATE에 넣은 재활용품을 카메라와 무게로 판정해 수거 여부를 정하는 AI 서버

개요

ECOMATE는 폐기물의 종류와 상태를 분석해 올바른 분리배출 방법을 알려 주는 교육용 분리수거 기기입니다. 폐기물을 올려놓으면 카메라 이미지와 무게 센서 값으로 배출할 수 있는 상태인지 판단하고, 맞게 버린 경우에는 서보 모터가 수거 장치를 움직여 분류합니다. 그렇지 않으면 모니터에 이유와 피드백 영상을 보여 주고 다시 시도하도록 안내하며, 배출 기록은 앱에서 피드백 목록으로 확인합니다.

웹응용소프트웨어공학과 전공 동아리 ONE의 2026 EXPO 작품으로 팀과 함께 만들고 있고, 저는 이 기기의 AI 서버를 맡았습니다.

판정 흐름

  1. 라즈베리파이의 카메라와 무게 센서가 이미지와 무게를 AI 서버로 보냅니다.
  2. YOLO 모델이 물체의 위치와 9종 품목 후보를 찾습니다.
  3. NAS의 Vision LLM이 전체 화면과 확대한 물체 이미지를 함께 보고 품목, 라벨, 압착, 이물질을 판정합니다. 라벨은 카메라 이미지로, 내용물이 남았는지는 무게로 구분합니다.
  4. YOLO가 물체를 못 찾으면 전체 화면으로 다시 판정하고, 비닐과 플라스틱처럼 헷갈리는 경우는 한 번 더 확인합니다.
  5. 규칙 엔진이 무게와 상태를 합쳐 수거, 거부, 일반 쓰레기, 미감지 중 하나로 확정하고 기기와 Spring 서버에 결과를 보냅니다.
flowchart TD
  P[Raspberry Pi 카메라 · 무게 센서] --> Y[YOLO 품목 후보]
  Y --> L[NAS Vision LLM 판정]
  L --> R[규칙 엔진]
  R --> H[기기 응답]
  R --> S[Spring 서버]

캔, 종이, 비닐, 플라스틱(페트병)은 분류하고, 건전지, 유리, 형광등, 스티로폼은 분류할 수 없는 품목으로 인식해 모니터에 안내합니다. 지금은 한 번에 하나씩 넣는 방식으로 설계했습니다.

맡은 일

  • FastAPI 분류 서버와 CI/CD 구성
  • 같은 입력으로 이전 판정을 다시 재현해 모델을 바꾸기 전후를 비교하는 검증 흐름
  • 평가용 데이터가 학습 후보에 섞이지 않도록 하는 데이터 누수 검사
  • NAS에 Vision LLM 게이트웨이를 올리고 HTTPS와 인증 적용
  • 요청 단계별 지연 시간과 모델 상태를 나눠 기록하는 운영 로그

검증 결과

AIHub 재활용품 데이터에서 9종을 30장씩 고정해 뽑은 270장으로, 라즈베리파이에서 운영 중인 판정 흐름 전체를 평가합니다. 처음에는 243/270(90.0%)이었고, YOLO와 LLM의 판정이 서로 어긋나는 경우에만 물체를 크게 잘라 한 번 더 판정하도록 고쳐서 정확도를 끌어올렸습니다.

평가 (2026-09-30) 결과
9종 정확도 259/270, 95.93%
플라스틱 27/30, 90.0% (이전 23/30)
위험 거부품 recall (유리, 건전지, 형광등, 스티로폼) 114/120, 95.0%
미감지·오류 0/270
평균 응답 시간 3.56초 (p95 6.19초)
새 카메라로 직접 찍은 품목 (22장, 소규모 확인) 22/22

이 수치는 같은 270장으로 모델과 판정 규칙을 바꾸기 전후를 비교하는 회귀 평가입니다. 다음 단계는 새 카메라로 9종을 30장 이상씩 직접 찍어, 학습과 튜닝에 쓰지 않은 데이터로 따로 평가하는 것입니다.
