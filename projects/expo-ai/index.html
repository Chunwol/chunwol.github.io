EXPO AI

제품 추론과 연구 검증을 분리해 모델 변경의 근거와 운영 안전성을 함께 관리

재활용품 이미지와 무게를 분석해 품목과 상태를 판정하고, 하드웨어와 Spring 서비스에 결과를 전달하는 AI 서버

개요

재활용품의 이미지와 무게를 받아 품목을 찾고 상태를 판정한 뒤, 하드웨어와 Spring 서비스가 사용할 수 있는 형태로 응답하는 FastAPI 기반 AI 서버입니다. 제품에서 사용하는 추론 경로와 모델을 개선하기 위한 데이터·검증 경로를 분리해 관리합니다.

이 이미지는 candidate_freeze20 후보 학습의 10 epoch 실험 산출물입니다. 운영 모델 승격이나 전체 품목 정확도 통과를 뜻하지 않으며, 실험과 운영 경로를 분리해 기록한 예시입니다.

기여 범위

  • FastAPI 분류 서버와 CI/CD 구성을 다룬 초기 Pull Request에 참여했습니다.
  • 고정된 모델과 입력으로 이전 판정을 재현하고, 원본 이미지에서 crop을 다시 생성해 결과를 비교하는 검증 흐름을 보강했습니다.
  • 보호 평가 자료가 연구 후보 데이터에 섞이지 않도록 누수 검사와 데이터 계보를 확인하는 작업을 진행했습니다.
  • 서버 응답, 모델 로드 상태, 요청별 지연 시간을 나눠 관측해 연결 성공과 실제 추론 완료를 구분했습니다.

운영 관측 요청 단계와 모델 상태를 로그로 분리해 병목과 실패 위치 확인

검증에서 중요하게 본 점

모델 파일, 원본 이미지, crop, 판정 정책의 지문을 함께 남겨 같은 입력을 다시 검증할 수 있게 했습니다. 단순히 파일이 존재하는지 보는 대신 bbox·class·confidence를 재생 결과와 대조하고, 가짜 판정 공급자가 공식 결과를 만들지 못하도록 경계를 나눴습니다.

테스트 통과, 데이터 준비, 새 모델 학습, 성능 향상, 하드웨어 end-to-end 검증은 서로 다른 완료 조건으로 관리합니다. 2026년 9월 기준 검증 도구와 운영 관측 경로는 보강됐지만, 새 연구 모델의 성능 개선과 독립 하드웨어 검증을 완료한 것으로 서술하지 않습니다.
