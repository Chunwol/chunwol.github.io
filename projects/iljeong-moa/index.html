화면

개요

공모전 포스터, 학교 공지, 과제 PDF에는 접수 마감, 발표, 심사 같은 날짜가 여러 개씩 흩어져 있어서, 캘린더에 옮기다 보면 빠뜨리기 쉽습니다. 일정모아는 이 자료를 사진·텍스트·문서 파일로 올리면 날짜와 장소를 읽어 공모전, 대회, 취업, 학교생활, 동아리 활동별로 묶고, 원본 자료와 세부 일정을 함께 보여 주는 캘린더 중심 Android 앱입니다. 스마트앱프로젝트 수업의 팀 프로젝트로 4명이 함께 만들고 있습니다.

브라우저에서도 동작 흐름을 체험할 수 있도록 인터랙티브 웹 데모를 별도로 공개했습니다.

맡은 일

팀장으로서 프로젝트 초기 구조, Room DB 스키마와 마이그레이션, 온디바이스 OCR·정규식·LLM 파이프라인, 선택형 클라우드 AI 연동, 홈 화면 위젯 4종과 자정 갱신 구조를 맡았습니다.

처리 흐름

flowchart TD
  A[사진 · 앨범 · 텍스트 · PDF/DOCX/HWPX] --> B[ML Kit + PaddleOCR · 문서 파서]
  B --> C[정규식 · java.time 날짜 초안 추출]
  C --> D{AI 인식 모드}
  D -->|로컬| E[Gemma 3 1B · MediaPipe]
  D -->|클라우드 선택 시| F[OpenRouter · Retrofit]
  E --> G[(Room DB v7)]
  F --> G
  G --> H[캘린더 · 활동 상세 · 위젯 4종 · 알림]

주요 기능

  • 다양한 자료 입력: 카메라 문서 스캐너, 앨범 사진(ML Kit 한국어 OCR + PaddleOCR 줄 단위 병합), 텍스트 붙여넣기, PDF·DOCX·HWPX·TXT 문서 첨부에서 일정 초안과 장소·요약 메모를 추출합니다.
  • 이중 AI 파이프라인: 기본 설정에서는 정규식과 기기 내 Gemma 3 1B 모델로 네트워크 없이 동작하고, 사용자가 설정에서 OpenRouter API 키를 입력해 클라우드 모드를 고르면 압축 이미지와 텍스트를 함께 보내 일정을 추출합니다.
  • 활동 단위 묶음과 원본 보관: 하나의 활동 아래 여러 세부 일정과 원본 자료(사진·문서 파일·원문 텍스트)를 함께 저장해, 일정 상세에서 등록 당시 자료를 바로 다시 열 수 있습니다.
  • 캘린더·상태·통계: 고정 월간 캘린더와 하루 단위 스와이프, 4단계 상태(예정·진행 중·종료·완료), 활동 상세 3탭(일정·상세 정보·자료), 마이페이지 월별 도넛 통계를 제공합니다.
  • 홈 화면 위젯 4종: 다가오는 일정(4×3), 다음 일정(2×2), 이번 달 달력(4×4), 일정 추가 바(4×1)를 제공하고, 공통 부모 클래스(EventWidgetProvider)와 WorkManager로 자정 자동 갱신과 마감 알림을 처리합니다.

데이터 구조

하나의 활동(activities) 아래에 원본 자료(sources)와 세부 일정(events)이 여러 개씩 연결되며, 일정마다 복수의 사전 알림(event_reminders)을 둘 수 있습니다. 활동에 묶지 않고 단독 일정만 등록하는 경로도 지원합니다.

erDiagram
  ACTIVITIES ||--o{ SOURCES : has
  ACTIVITIES ||--o{ EVENTS : has
  SOURCES ||--o{ EVENTS : extracts
  EVENTS ||--o{ EVENT_REMINDERS : notifies

기술 선택

구분 사용 기술 이유
개발 Kotlin 2.0, JDK 17, XML Views, ViewPager2 팀 협업에 맞춘 모듈 분리와 캘린더·탭 화면 구성
저장 Room 2.6 (DB v7), SQLite, 앱 내부 저장소 로그인·계정 서버 없이 기기 안에서 원본과 일정 완결
문자·문서 인식 ML Kit Text Recognition v2, PaddleOCR, 문서 파서 사진·스캔 이미지와 PDF·DOCX·HWPX 텍스트를 함께 추출
일정 구조화 정규식 + java.time, Gemma 3 1B (MediaPipe) / OpenRouter (Retrofit + Gson) 온디바이스 우선 처리와 선택형 클라우드 보완 지원
위젯·알림 App Widget (RemoteViews), WorkManager 4종 위젯 자정 동기화와 일정별 마감 알림 제공

현재 단계와 다음 작업

에뮬레이터와 JVM 기준 단위 테스트 1,194건, SQLite DB 계측 테스트 28건, OCR 계측 테스트 23건과 PDF·DOCX·HWPX 인식 검수를 통과했고 GitHub Actions CI도 정상 동작하고 있습니다. 다음 작업은 lint 오류 2건 정리, 온디바이스 모델 다운로드/가져오기 방식 확정, 실기기 환경에서의 클라우드 AI·전체 E2E 최종 점검입니다.
