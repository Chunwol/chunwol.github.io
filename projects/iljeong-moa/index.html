일정모아

포스터, 공지, PDF 속 날짜를 기기 안에서 읽어 공모전, 대회, 과제별 일정으로 정리하는 Android 앱

개요

공모전 포스터, 학교 공지, 과제 PDF에는 접수 마감, 발표, 심사 같은 날짜가 여러 개씩 흩어져 있어서, 캘린더에 옮기다 보면 빠뜨리기 쉽습니다. 일정모아는 이 자료를 사진이나 파일로 올리면 날짜를 읽어 공모전, 대회, 과제, 팀플별로 묶고, 원본 자료와 세부 일정을 함께 보여 주는 캘린더 중심 Android 앱입니다. 스마트앱프로젝트 수업의 팀 프로젝트로 4명이 진행하고 있습니다.

맡은 일

팀장으로서 초기 설정과 핵심 로직, OCR과 LLM 연동, DB와 원본 저장을 맡았습니다.

처리 흐름

flowchart TD
  A[포스터 · 공지 · PDF] --> B[ML Kit 문자 인식]
  B --> C[정규식 · java.time 날짜 추출]
  C --> D[Gemma 3 1B 항목 분리]
  D --> E[(Room DB)]
  E --> F[월간 캘린더 · 위젯 · 알림]

데이터 구조

하나의 활동(공모전, 과제 등) 아래에 원본 자료와 세부 일정이 여러 개씩 딸립니다. 원본을 앱 내부 저장소에 함께 보관해서, 날짜를 다시 확인하고 싶을 때 자료로 돌아갈 수 있습니다.

기술 선택

구분 사용 기술 이유
개발 Kotlin 2.0, JDK 17, 네이티브 View/XML 모듈을 나누고 캘린더 중심 화면 구성
저장 Room 2.6, SQLite, 앱 내부 저장소 로그인, Firebase, 서버 없이 기기 안에서 완결
문자 인식 ML Kit Text Recognition v2 (한국어) 기기 안에서 동작하고 호출 제한이 없음
항목 분리 정규식 + java.time, Gemma 3 1B (MediaPipe) int4 모델을 APK에 포함해 기기에서 추론
위젯, 알림 App Widget, WorkManager 월간, 일정, 작은 일정 위젯과 알림

설계 원칙

서버 없이 모든 처리를 기기 안에서 끝냅니다. 사진 속 문자 인식부터 일정 항목 분리까지 네트워크 없이 동작합니다.

현재 단계와 다음 작업

핵심 로직과 단위 테스트까지 구현했습니다. 다음 순서는 데모 UI, 위젯 Provider, 실기기 end-to-end 테스트입니다.
