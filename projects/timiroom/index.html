개요

자연어로 적은 요구사항을 받아 기능 명세, API 설계, DB 스키마를 자동으로 생성하고, 설계가 바뀌었을 때 영향을 받는 범위를 지식 그래프로 보여주는 서비스입니다. 기획과 개발 사이의 정합성을 지키는 것이 목표입니다.

2026-09-28 실제 서비스에서 캡처한 랜딩 페이지입니다. 로그인 뒤의 문서 생성 화면과 설계 정합성 기능은 운영 정보가 드러나지 않는 자료를 준비해 추가할 계획입니다.

맡은 일

  • Java 21, Spring Boot 기반 백엔드와 RAG 멀티 에이전트 파이프라인 개발
  • Spring Security, OAuth2, Redis Session으로 인증 구성
  • Spring Data JPA로 PostgreSQL을 연동하고 Neo4j, Kafka 연결
  • WebFlux와 SSE로 AI 문서 생성 진행 상태를 실시간으로 전달
  • GitHub App 연동과 설계 정합성 검증 기능 개발
  • K3s 환경에 배포하고 운영

핵심 기능

기능 설명
설계 자동화 요구사항을 LLM이 분석해 기능 명세, API 설계, DB 스키마 생성
지식 그래프 기획, API, DB 사이의 연결을 그래프로 시각화해 의존성 파악
정합성 검증 설계 변경이 전체에 미치는 영향을 시뮬레이션해 오류를 미리 탐지
버전 관리 설계 변경 이력을 스냅샷으로 저장해 비교, 롤백
명세 추출 확정된 설계를 Swagger, Mermaid 형식으로 추출

구조

flowchart TD
  C[Client · Next.js] --> N[Nginx · SSL]
  N --> A[Spring Boot API · REST / SSE]
  A --> O[멀티 에이전트 오케스트레이터]
  O --> PM[PM 에이전트]
  O --> DBA[DBA 에이전트]
  O --> API[API 에이전트]
  PM & DBA & API --> V[설계 검증 엔진]
  V --> H[버전 관리]
  H --> PG[(PostgreSQL + pgvector)]
  H --> NEO[(Neo4j)]
  H --> R[(Redis)]

기술: Java, Spring Boot, Next.js, PostgreSQL, Neo4j, Redis, Kafka, Kubernetes, RAG
