# 일정모아 웹 데모

https://chunwol.github.io/schedulehub/

캘린더와 활동별 여러 일정을 직접 눌러보는 HTML·CSS·JavaScript 데모입니다.

일정 등록·수정·완료, 활동 중단·복원, 텍스트 날짜 정리, 검색, 사진 미리보기, 위젯 미리보기를 사용할 수 있습니다. 입력 내용은 각 브라우저에만 저장됩니다.

실제 OCR·AI·문서 본문 추출·기기 알림은 연결하지 않았습니다. 예제 날짜와 D-day 기준일은 2026년 10월 8일입니다.

## 유지보수

이 폴더는 기존 포트폴리오와 독립된 정적 페이지입니다. 포트폴리오를 다시 발행할 때 `dongyanghotel/`, `stopWatch/`와 함께 `schedulehub/`도 보존해야 합니다. 이 폴더의 파일만 교체하면 되며 Pages 설정이나 다른 페이지를 바꿀 필요가 없습니다.

- `index.html`: 페이지 골격
- `styles.css`: 반응형 화면
- `app.js`: 화면 조작과 브라우저 저장
- `domain.js`: 날짜·일정 데이터 처리
- `assets/`: Lucide 아이콘, ISC 라이선스 포함

Android 소스·모델·개인 데이터·검증용 캡처는 포함하지 않습니다.
