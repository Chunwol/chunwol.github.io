기술

Backend
  • Java
  • Spring Boot
  • Node.js
  • Express
  • TypeScript

Spring Security, OAuth2, Redis Session으로 인증을 구성하고 WebFlux와 SSE로 진행 상태를 스트리밍합니다. Express에서는 RESTful 설계와 미들웨어 기반 에러 핸들링을 다룹니다.

Data
  • PostgreSQL
  • MySQL
  • Redis
  • Neo4j
  • Kafka
  • Prisma

  • Kubernetes

  • Nginx
